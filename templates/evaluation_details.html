Evaluation Details

The evaluation follows the OmniDocBench v1.5 end-to-end evaluation framework.

How It Works

  1. Parsing: Your submitted .md files are parsed to extract text blocks, formulas ($$...$$), and tables (<table>).
  2. Matching: Extracted elements are matched against the ground truth annotations using the quick_match algorithm based on content similarity.
  3. Scoring: Matched pairs are scored per dimension.

Metrics

1. Text Edit Distance (↓ lower is better)

Normalized Levenshtein edit distance between predicted and ground-truth text blocks. Averaged across all matched text elements per page, then across all pages.

2. Table TEDS (↑ higher is better, 0–100)

Tree Edit Distance-based Similarity measures structural and content accuracy of tables. Ground truth and predictions are compared as HTML tree structures.

3. Formula CDM (↑ higher is better, 0–100)

Character Detection Matching renders both ground truth and predicted LaTeX formulas into images, then performs character-level spatial matching. This is more fair than string-based metrics since the same formula can have multiple valid LaTeX representations.

Overall Score

Overall = ((1 − Text_ED) × 100 + Table_TEDS + Formula_CDM) / 3

All three dimensions are weighted equally. Rankings on the leaderboard are determined by the Overall score (higher is better).
