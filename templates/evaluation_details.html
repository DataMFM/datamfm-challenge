Evaluation Details

Submissions are routed by the required Task metadata. Dev Phase and Test Phase select the evaluation split, while Task selects the evaluator.

Document Parsing Evaluation

Document Parsing follows the OmniDocBench md2md evaluation pipeline. Submitted Markdown files are matched against document-level ground truth Markdown files with quick matching.

Text ED (lower is better)

Normalized Levenshtein edit distance between predicted and ground-truth text blocks.

Table TEDS (higher is better, 0-100)

Tree Edit Distance-based Similarity measures table structure and content agreement.

Formula CDM (higher is better, 0-100)

Character Detection Matching compares rendered LaTeX formulas using character-level matching.

Reading Order (higher is better, 0-100)

Reading order is computed from reading order edit distance as (1 - Reading_Order_ED) * 100.

Document Overall

Overall = ((1 - Text_ED) * 100 + Table_TEDS + Formula_CDM + Reading_Order) / 4

Chart Understanding Evaluation

Chart Understanding evaluates JSONL predictions for chart-to-CSV and chart-to-summary tasks over real and synthetic chart splits.

CSV Numeric F1

Numeric values extracted from predicted CSV outputs are matched against reference numeric values with tolerance.

CSV Structural Score

Predicted CSV outputs are compared with references using row count, column count, and header agreement.

Summary ROUGE-L

Predicted chart summaries are compared against reference summaries using ROUGE-L F1.

Summary Numeric Fact F1

Numeric facts in predicted chart summaries are matched against numeric facts in reference summaries.

Chart Overall

Overall = (CSV_Numeric_F1 + CSV_Structural_Score + Summary_ROUGE_L + Summary_Numeric_Fact_F1) / 4

Result Storage

For both tasks, the remote worker saves the uploaded archive, extracted predictions, raw metric files, final scores, and request metadata for each submission. These artifacts are used to audit submissions and maintain the external chart leaderboard.
