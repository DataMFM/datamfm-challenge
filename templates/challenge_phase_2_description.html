Test Phase

The test phase evaluates models on the held-out test split for final ranking.

Details

  • Dataset: Test split (20% of OmniDocBench pages)
  • Submissions: 5 per day, 30 per month
  • Leaderboard: Public — final rankings
  • Format: .zip containing .md files (one per page)

This phase opens after the dev phase. Final challenge rankings and awards are based on test phase scores.

Note: Top-ranked teams must submit a technical report describing their method. External data usage must be disclosed.
