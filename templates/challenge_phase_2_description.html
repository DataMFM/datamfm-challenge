Test Phase

The test phase evaluates submissions on the held-out test split. This phase is shared by both Document Parsing and Chart Understanding.

Details

  • Split: Test split for the selected Task.
  • Task selection: Choose Document Parsing or Chart Understanding in the required Task metadata field.
  • Submissions: 5 per day, 30 per month.
  • Format: Upload a .zip whose internal structure matches the selected Task.
  • Leaderboard: EvalAI shows the Document Parsing leaderboard. Chart results are saved for the external DataMFM chart leaderboard.

Final rankings and awards are determined by the organizers using the appropriate leaderboard for each Task.

Note: Top-ranked teams must submit a technical report describing their method. External data usage must be disclosed.
