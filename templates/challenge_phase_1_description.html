Dev Phase

The development phase evaluates submissions on the dev split. This phase is shared by both Document Parsing and Chart Understanding.

Details

  • Split: Dev split for the selected Task.
  • Task selection: Choose Document Parsing or Chart Understanding in the required Task metadata field.
  • Submissions: 10 per day, 100 per month.
  • Format: Upload a .zip whose internal structure matches the selected Task.
  • Leaderboard: EvalAI shows the Document Parsing leaderboard. Chart results are saved for the external DataMFM chart leaderboard.

Use this phase to develop, debug, and iterate before submitting to the test split.
