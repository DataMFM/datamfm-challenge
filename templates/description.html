DataMFM End-to-End Document Parsing Challenge

The DataMFM Challenge focuses on end-to-end document parsing — given a document page image, produce a complete Markdown representation that accurately captures text, tables, and mathematical formulas.

This challenge is part of the Emerging Directions in Data for Multimodal Foundation Models (DataMFM) workshop at CVPR 2026.

Task

Given document page images from the OmniDocBench dataset, participants must generate Markdown files (.md) that faithfully represent the content of each page, including:

  • Text: Paragraphs, titles, headers, footers, captions
  • Tables: Structure and cell contents (HTML <table> format recommended)
  • Formulas: Mathematical equations in LaTeX notation ($$...$$)

Evaluation

Submissions are evaluated on three dimensions following the OmniDocBench evaluation framework:

  1. Text Recognition — Normalized Edit Distance (lower is better)
  2. Table Recognition — TEDS: Tree Edit Distance-based Similarity (0–100, higher is better)
  3. Formula Recognition — CDM: Character Detection Matching (0–100, higher is better)

Overall Score

Overall = ((1 − Text_Edit_Distance) × 100 + Table_TEDS + Formula_CDM) / 3

Dataset

The challenge uses OmniDocBench data — a comprehensive document parsing benchmark covering 981 pages from 113 PDF documents across 9 data types (academic papers, slides, financial reports, etc.) in English, Chinese, and mixed-language documents.

Organizers
