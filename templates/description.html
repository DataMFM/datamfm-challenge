DataMFM Challenge

The DataMFM Challenge provides a shared submission portal for two multimodal data understanding tasks: Document Parsing and Chart Understanding.

This challenge is part of the Emerging Directions in Data for Multimodal Foundation Models (DataMFM) workshop at CVPR 2026.

Tasks

Document Parsing asks participants to convert document content into Markdown that preserves text, tables, formulas, and reading order. The evaluator follows the OmniDocBench-style md2md pipeline.

Chart Understanding asks participants to predict structured chart data and chart summaries. The evaluator compares submitted JSONL predictions against real and synthetic chart ground truth files.

How to Submit

Use the existing Dev Phase or Test Phase to choose the evaluation split. Then choose Task in the submission metadata to select either Document Parsing or Chart Understanding. The uploaded .zip format must match the selected Task.

Document Parsing Metrics

  • Text ED: Normalized edit distance for text recognition. Lower is better.
  • Table TEDS: Tree Edit Distance-based Similarity for table recognition. Higher is better.
  • Formula CDM: Character Detection Matching for formula recognition. Higher is better.
  • Reading Order: Reading order score converted from edit distance. Higher is better.

Chart Understanding Metrics

  • CSV Numeric F1: Numeric agreement between predicted and reference chart data.
  • CSV Structural Score: Agreement in CSV table shape and headers.
  • Summary ROUGE-L: Text overlap for chart summaries.
  • Summary Numeric Fact F1: Numeric fact agreement in chart summaries.

Leaderboards

The EvalAI leaderboard is used for Document Parsing. Chart Understanding submissions are evaluated and saved by the remote worker, and chart rankings are maintained on the DataMFM challenge website.
